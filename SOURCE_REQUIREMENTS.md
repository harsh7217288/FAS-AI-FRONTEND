# Requirements captured from the provided README

The frontend is designed around the provided project architecture:
- Next.js frontend
- FastAPI backend on port 8000
- PostgreSQL/PostGIS
- OAuth2 + JWT
- Sentinel-2 L2A
- OpenWeather
- Rasterio + NumPy
- Scikit-learn Random Forest
- Leaflet for field boundary capture

The UI exposes:
- Dashboard
- Field management + polygon boundary selection
- Satellite monitoring / NDVI
- Weather
- Crop health
- Soil
- Pest & disease risk
- Alerts
- AI Assistant / image upload
- Reports / analytics
- About / How It Works / Contact
- Mobile OTP-style authentication UI requested by the frontend owner
- English/Hindi toggle across all routes

The provided PDF is visual reference material; its pages were image-based and did not contain machine-readable text. Reference images were extracted to `public/images/`.
